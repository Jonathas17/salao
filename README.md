# 📝 README – Versatil Cabeleleiros
## 💇‍♀️ Versatil Cabeleleiros – Website Oficial

Website moderno, responsivo e otimizado para o salão de beleza Versatil Cabeleleiros.
O projeto foi desenvolvido com foco em elegância, performance e experiência do usuário, contando com:

✨ Slider profissional em alta resolução
✨ Sistema de agendamento com seleção de serviço, calendário e horários
✨ Envio automático para WhatsApp
✨ Layout responsivo e animações suaves
✨ Painéis de preços, equipe, serviços e localização interativa

# 🚀 Tecnologias Utilizadas
Frontend

HTML5

CSS3 (com design responsivo)

JavaScript (ES6+)

Google Fonts

Backend

Possibilidade futura de integração com Node.js + MySQL
